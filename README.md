# AI-Assisted Radar ECU Troubleshooting System

## Overview
This thesis project focuses on a semi-automated AI-assisted troubleshooting system for Radar ECU testbenches using Retrieval-Augmented Generation (RAG) and cloud LLMs.

## Structure

- src/ -> source code
- knowledgeBase/ -> raw knowledge sources
- processed/ -> cleaned/processed data
- tests/ -> test scripts
- docs/ -> thesis documentation
